# BookCringe Intelligence

## Visão

Ser a central de inteligência do BookCringe.

Toda decisão editorial deve ser suportada por dados.

---

## Missão

Transformar dados de plataformas diferentes em conhecimento útil.

---

## Problema

Hoje o criador precisa abrir:

- YouTube Studio
- Instagram
- TikTok
- Meta Ads
- Google Analytics

Cada plataforma responde apenas perguntas sobre ela mesma.

Nenhuma responde perguntas sobre o negócio como um todo.

---

## Solução

O Intelligence centraliza tudo.

Depois transforma tudo em um modelo canônico.

Depois gera análises.

Depois recomenda decisões.

Depois transforma decisões em ações — o Dashboard vira uma central de
trabalho diário, não só um mural de números.

---

## Princípios

- O Dashboard nunca lê arquivos.
- Toda plataforma possui seu próprio Adapter.
- O domínio pertence ao BookCringe.
- Dados são separados da interpretação.
- Cada Sprint entrega valor.
- Simplicidade acima de abstração.
- Nunca duplicar dados do CMS.
- Toda recomendação deve virar uma ação clicável.

---

## Manifesto

O Intelligence não existe para importar arquivos.

Não existe para mostrar gráficos.

Não existe para armazenar dados.

Ele existe para responder:

"Qual é a próxima melhor decisão para o BookCringe?"
